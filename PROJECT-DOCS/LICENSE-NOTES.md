# Licence Notes

## Objective
Finance Suite may eventually become a commercial SaaS product.

Therefore every external dependency must be licence-reviewed before incorporation.

## Preferred Licences
Prefer permissive licences such as:
- MIT
- Apache 2.0
- BSD

## Rule
Before importing any code:
1. Check current LICENSE file
2. Record repository URL
3. Record commit/tag
4. Record licence
5. Preserve required copyright notices
6. Document modifications
7. Confirm commercial compatibility

## Standards Copyright
IFRS, tax authority material and professional standards may have separate copyright/licensing rules.

Do not assume open-source software licensing gives rights to reproduce standards text.
